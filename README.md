# Financy

Aplicação fullstack de gestão financeira (transações e categorias), desenvolvida como desafio prático da pós-graduação.

- [`backend/`](./backend) — API GraphQL (Express + Apollo Server + TypeGraphQL + Prisma + SQLite)
- [`frontend/`](./frontend) — SPA React + Vite + Apollo Client

Veja o README de cada pasta para instruções de setup.
